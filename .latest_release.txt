# 0.6.9

Security
- Update dependencies, fixing all 31 RustSec advisories that applied to
  0.6.8. They include request smuggling and memory exhaustion in
  actix-web/actix-http (RUSTSEC-2026-0446, -0447, -0448, -0455) (#47)

Docker image
- Built on the stable Alpine 3.24 base image instead of Alpine edge (#47)

New
- Support Sportarr and other Transmission clients that follow the RPC spec
  strictly: numeric rpc-version and torrent status, percentDone, the added
  torrent in the torrent-add reply, and session-stats (#46)
- Magnets with a base32 info hash keep their category, because the hash is
  now converted to the hex form put.io reports (#46)

Fixes
- An unknown RPC method is logged as a warning instead of crashing the
  request handler (#46)
